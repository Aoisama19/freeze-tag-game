## Generated by this project

The sound effects in `Assets/_Project/Audio/Generated` are synthesised by
`SoundBuilder.cs`. The map pictures in `Assets/_Project/Art/UI/MapPreviews` are
rendered from this game's own scenes by `MapPreviewBuilder.cs`. Both are produced
from code in this repository rather than sourced from anywhere.

## The author's own work
